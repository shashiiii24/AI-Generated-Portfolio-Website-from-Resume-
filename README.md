# 🤖 AI-Generated Portfolio Website from Resume

An AI-powered web application that automatically creates a professional portfolio website from a user’s resume using Generative AI.

Upload your resume → get a complete HTML, CSS, and JavaScript portfolio website in seconds.
--

## 🚀 Features

📄 Upload resume (PDF / DOCX)

🧠 AI extracts skills, education, and projects

🎨 Generates a clean, professional portfolio website

🌓 Light & Dark mode support

🌐 Live website preview inside Streamlit

📦 Download website files as a ZIP

🔁 Handles AI model overload with retry logic
--

## 🛠️ Tech Stack

Frontend: Streamlit

Backend: Python

AI / LLM: Google Gemini

LLM Framework: LangChain

Resume Parsing: PyPDF2, python-docx

--

# ⚙️ Setup & Run
## 1️⃣ Clone the repository

```bash
git clone https://github.com/shashiiii24/AI-Generated-Portfolio-Website-from-Resume-.git
```

## 2️⃣ Install dependencies
```bash
pip install -r requirements.txt
```

## 3️⃣ Add API key
```bash
Create a .env file:

gemini=YOUR_GOOGLE_GEMINI_API_KEY
```
## 4️⃣ Run the app
```bash
streamlit run main.py
```

## 🧠 How It Works

- User uploads resume

- Resume text is extracted

- AI analyzes the content

- Portfolio website is generated (HTML/CSS/JS)

- Live preview is shown

- Website files are downloaded as ZIP

- Student portfolios

- Aspiring Data Scientists

- Resume-to-Website automation

- Personal branding projects
